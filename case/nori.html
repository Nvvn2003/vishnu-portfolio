Nori — Snack Packaging

Six flavours that looked like six different brands. We built one system to rule them all.

RolePackaging & Visual System
Year2023
ServicesPackaging · System · Illustration
TypeVisual System
OverviewThe brief

Nori's range had grown one SKU at a time with no shared logic. On shelf it read as chaos. The job was to turn a scattered set of products into one confident, scalable brand system.

01Challenge

Shoppers couldn't tell the products belonged together, which diluted recognition and repeat purchase. Internally, every new flavour meant starting design from a blank page — slow and inconsistent.

02Approach

We created a single, flexible packaging system: one grid, bold flavour-coded colour blocks, and a mascot that scales across the whole range. Adding a new SKU became a matter of dropping into the template, not reinventing it.

The result reads as one brand from across the store — while each flavour still pops.

03Outcome

A unified shelf block that finally looks like one brand — lifting repeat purchase and dramatically speeding up how fast new products can ship.
